# Assignment 4. Forms and Validation

**Student:** Baktybay Nazar  **Group:** SE_2530

## Description
A multi-page website with HTML forms, Bootstrap form styling and validation.
The navbar on every page links to all tasks.

| Page | Content |
| --- | --- |
| `index.html` | Home page with links to all tasks |
| `task0.html` | Simple contact form (Name, Email, Message) with `<label>`s, styled with `style.css` |
| `task1.html` | Same form with HTML5 validation (`required`, `type`, `minlength`, `maxlength`, `pattern`) |
| `task2.html` | Contact form recreated with Bootstrap form classes, grid, placeholders, helper text |
| `task3.html` | Bootstrap validation styles (`is-valid`, `is-invalid`) with feedback messages |
| `task4.html` | Registration form: names, email, passwords, gender, hobbies, country, Submit/Reset |

## Files
- `style.css` - custom CSS, used only for Task 0 (and Task 1, which uses the same form)
- `validation.js` - JavaScript, used only for form validation (Tasks 3 and 4)
- Bootstrap 5.3 is loaded from a CDN

## How to run
1. Clone the repository or download it.
2. Open `index.html` in a browser (internet is needed for the Bootstrap CDN).
